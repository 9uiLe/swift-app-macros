# Security Policy

## Supported versions

`swift-app-macros` is an early-stage package. Security fixes are provided only
for the latest released version (or `master` before the first tagged release).

| Version        | Supported |
|----------------|-----------|
| Latest release | ✅        |
| Older releases | ❌        |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub's
[private vulnerability reporting](https://github.com/9uiLe/swift-app-macros/security/advisories/new)
("Report a vulnerability" on the repository's **Security** tab). This keeps the
report confidential until a fix is available.

When reporting, please include:

- A description of the issue and its impact.
- Affected version / commit.
- Minimal steps or a code sample to reproduce.

You can expect an initial acknowledgement within a reasonable timeframe. Because
this is a solo-maintained project, please allow time for triage and a fix before
any public disclosure.
